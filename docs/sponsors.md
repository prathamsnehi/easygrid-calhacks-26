## Extra deliverables and eligibility that affect project choice

- **Fetch:** **Devpost + ASI:One Submission Agent** required; public repo, Devpost URL, video. Teammates join Team ID until **Submitted**. [Instructions][fetch-submit].

- **CREAO:** put **agent ID + run-share link** in the Devpost README and select the CREAO track. [Starter pack]([https://community.creao.ai/CalHacks2026](https://community.creao.ai/CalHacks2026)).

- **Atlassian:** actual **Forge app**; provision demo site early. **Three-minute maximum video + repository** in Devpost. [Brief][atlassian].

- **Figma:** **Edu verified; Anyone-accessible files; video ≤3min; Figma Slides, repo and embedded Figma files required.** Log **≤200 words/stage**: tools/why, minutes, 1–5 rating, contribution. [Brief][figma].

- **Hyphenate:** demo video opens with standout moment; live demo, one line on finance roles filled, evidence distinguishing real/simulated behavior. [Brief]([https://docs.google.com/document/d/1u4iN8R97ILY3kfHTPKC82zdutHrGx4ze5eCAP-J92w4/edit](https://docs.google.com/document/d/1u4iN8R97ILY3kfHTPKC82zdutHrGx4ze5eCAP-J92w4/edit)).

- **Coinbase:** one primary track; summary, demo/setup, architecture/controls, builder feedback. Real money unnecessary; label simulations. **18+, US/Canada excluding Quebec, verified Coinbase account; one prize/person**. [Brief][coinbase].
